Quickstart

Shared Inference serves open models from community-run nodes behind an OpenAI-compatible API. Point any OpenAI SDK or coding harness at the base URL below.

Preview. Chat completions run on community nodes now. A model is only listed while nodes hold every layer of it. POST /responses, which Codex CLI needs, isn't served yet.

https://YOUR-HOST/api/v1

Requests authenticate with Authorization: Bearer <key>. The API serves GET /models and POST /chat/completions (including "stream": true). Text messages only; tool calls aren't supported.

Get an API key

Create a key on the API keys page, then keep it in an environment variable. Every example on this page reads it from there.

export SHAREDINFERENCE_API_KEY="si-..."

Make your first request

curl https://YOUR-HOST/api/v1/chat/completions \
  -H "Authorization: Bearer $SHAREDINFERENCE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "qwen2.5-7b-instruct",
    "messages": [{"role": "user", "content": "What is distributed inference?"}]
  }'
import os
import requests

response = requests.post(
    "https://YOUR-HOST/api/v1/chat/completions",
    headers={"Authorization": f"Bearer {os.environ['SHAREDINFERENCE_API_KEY']}"},
    json={
        "model": "qwen2.5-7b-instruct",
        "messages": [{"role": "user", "content": "What is distributed inference?"}],
    },
)
print(response.json()["choices"][0]["message"]["content"])
const response = await fetch('https://YOUR-HOST/api/v1/chat/completions', {
  method: 'POST',
  headers: {
    Authorization: `Bearer ${process.env.SHAREDINFERENCE_API_KEY}`,
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({
    model: 'qwen2.5-7b-instruct',
    messages: [{ role: 'user', content: 'What is distributed inference?' }],
  }),
});
const data = await response.json();
console.log(data.choices[0].message.content);

Using the OpenAI SDK

The official SDKs work unchanged once you set the base URL and key.

import os
from openai import OpenAI

client = OpenAI(
    base_url="https://YOUR-HOST/api/v1",
    api_key=os.environ["SHAREDINFERENCE_API_KEY"],
)

completion = client.chat.completions.create(
    model="qwen2.5-7b-instruct",
    messages=[{"role": "user", "content": "What is distributed inference?"}],
)
print(completion.choices[0].message.content)
import OpenAI from 'openai';

const client = new OpenAI({
  baseURL: 'https://YOUR-HOST/api/v1',
  apiKey: process.env.SHAREDINFERENCE_API_KEY,
});

const completion = await client.chat.completions.create({
  model: 'qwen2.5-7b-instruct',
  messages: [{ role: 'user', content: 'What is distributed inference?' }],
});
console.log(completion.choices[0].message.content);

Coding harnesses

Each harness below takes a custom OpenAI-compatible provider. Set SHAREDINFERENCE_API_KEY first.

Codex CLI

Add a provider to your user-level config. Codex only speaks the Responses API, so it uses /responses rather than chat completions. That endpoint isn't served yet.

~/.codex/config.toml
model = "qwen2.5-7b-instruct"
model_provider = "sharedinference"

[model_providers.sharedinference]
name = "Shared Inference"
base_url = "https://YOUR-HOST/api/v1"
env_key = "SHAREDINFERENCE_API_KEY"
wire_api = "responses"

opencode

Register the provider, then pick the model with /models.

opencode.json
{
  "$schema": "https://opencode.ai/config.json",
  "provider": {
    "sharedinference": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "Shared Inference",
      "options": {
        "baseURL": "https://YOUR-HOST/api/v1",
        "apiKey": "{env:SHAREDINFERENCE_API_KEY}"
      },
      "models": {
        "qwen2.5-7b-instruct": { "name": "Qwen2.5 7B Instruct" }
      }
    }
  }
}

Aider

Aider routes openai/ models to any compatible base URL.

export OPENAI_API_BASE=https://YOUR-HOST/api/v1
export OPENAI_API_KEY=$SHAREDINFERENCE_API_KEY
aider --model openai/qwen2.5-7b-instruct

Continue

Add the model to your Continue config and store the key as a secret.

~/.continue/config.yaml
name: Shared Inference
version: 0.0.1
schema: v1
models:
  - name: Shared Inference
    provider: openai
    model: qwen2.5-7b-instruct
    apiBase: https://YOUR-HOST/api/v1
    apiKey: ${{ secrets.SHAREDINFERENCE_API_KEY }}

Frameworks

import { createOpenAICompatible } from '@ai-sdk/openai-compatible';
import { generateText } from 'ai';

const sharedInference = createOpenAICompatible({
  name: 'sharedinference',
  baseURL: 'https://YOUR-HOST/api/v1',
  apiKey: process.env.SHAREDINFERENCE_API_KEY,
});

const { text } = await generateText({
  model: sharedInference('qwen2.5-7b-instruct'),
  prompt: 'What is distributed inference?',
});
console.log(text);
import os
from langchain_openai import ChatOpenAI

llm = ChatOpenAI(
    model="qwen2.5-7b-instruct",
    base_url="https://YOUR-HOST/api/v1",
    api_key=os.environ["SHAREDINFERENCE_API_KEY"],
)
print(llm.invoke("What is distributed inference?").content)

Models
