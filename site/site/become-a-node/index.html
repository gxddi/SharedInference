Become a node

Connect this computer to Shared Inference from your terminal.

  1. Install sinference

    Loading install command…

    Linux or macOS with Python 3.10+ and curl. Installs to ~/.local/bin. Read the installer

  2. Connect your account

    Loading setup command…

    Open the link it prints on any device, sign in, and approve if the name and code match.

  3. Choose a model

    Keep the command running to stay connected, then pick what this computer serves on your nodes. The first time, it also asks for a devnet wallet to stake from and get paid to (or add it on your nodes page). Your sign-in is saved for next time. Remove it with sinference logout.

Early preview: stakes and payouts use Solana devnet SOL, free from faucet.solana.com.
